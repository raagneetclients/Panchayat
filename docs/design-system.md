# Dhar civic design system

Hindi-first public information. The same content hierarchy and routes are available in English.

Tokens: government green #245C43; dark green #173F30; text #263747; secondary text #59666E; saffron #D99543; ivory #FAF8F2; border #E1E6DF; pale green #EEF3EC. Logo artwork is original, unrecoloured.

Typography: locally served Noto Sans Devanagari Variable and Inter Variable; font-display swap. Devanagari line height 1.75–2; body defaults to 15px with larger reading text and 90–120% adjustable root size. Headings are modest and left aligned. English and Hindi copy are explicit content fields, never runtime AI translation.

Layout: maximum content width 1260px; desktop gutters 48px, tablet 24px and mobile 18px. Breakpoints at 1180, 1000, 700 and 370px. Scheme directory 3/1 columns; quick services 8/4 columns; inner page content plus contextual sidebar; map has a text alternative.

Interaction: restrained hover changes, visible 3px keyboard focus, labelled native form fields, semantic details/summary, no essential animations; respects reduced motion. Mobile input text is at least 16px. The advertising popup uses a native dialog with focus trapping, close button, Escape dismissal and once-per-session display. The user expressly requested this popup.

Components: Header, Footer, Icon, Source, Callout, SectionTitle, SchemeDirectory, BlockDirectory, NoticeList, DistrictMap, BidForm, ApprovedAds and ReviewButtons.

Prototype status is visible in header/footer, noindex response and robots directives. State emblem and CM photo are identity references; their presence implies no endorsement of advertisements.
